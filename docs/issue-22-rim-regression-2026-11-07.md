# issue #22 边框回归检查（2026-11-07，`0.7.2`）

[issue #22「UI边框问题」](https://github.com/NoNameLeGo/dsh-catppuccin-theme/issues/22)（`moon16u`）报了三条，
0.6.2 修复、之后又有一轮四条的补丁，最后由报告人验收关闭。本次只做**回归实测**：这些边框还在不在、有没有变味。

环境：官方壳 `0.2.2-rc.1` + 插件 `0.7.2`、1280×822（dpr 1.5）。
配置：Latte×云母、Latte×兼容、Mocha×云母（三套，另含弹层与设置态，共 7 次取样）。

## 判据

读**计算样式**里真正会绘制的那部分，而不是只比 width/color：

- 一条边算「画出来了」必须同时满足 `border-style ≠ none/hidden`、`width > 0`、颜色 alpha > 0.01；
- 再对同一元素的四条边比 `width + color` 是否一致（#22-① 那次的本质是「右侧单独一条 40% 品牌的亮线」）；
- 另看 `outline` 与 `box-shadow`（`inset` 内环是 #22-③ 的那类描边）。

> 踩坑记录：第一版只看 width/color，把会话行左右那两条 **2.67px 透明**的树形缩进线（`border-style: solid`
> 但颜色全透明）误报成「左右不对称的边」；加上 style 与 alpha 判据后归零。**透明边不是边。**

细节读数：

- 侧栏卡片 / 顶栏卡片 / 输入卡 / 消息气泡 / 设置对话框面板：**四边 width 与色值逐一相同**

- Mocha 下同一批座位四边也一致（16% / 24% / 30%）；暗色菜单表面有一条 `0.667px solid 16%`
  的 `outline` —— 这是暗色专用设计（深影在深底上不显影，需要描边把面切出来），不是残留。
- 兼容模式：仅输入卡与气泡有边，且四边一致；弹层无 border/outline（0.6.2 起兼容路径的实线已删）。

## 目视复核

- `rim-corner-sidebar.png`（Latte，8×）/ `rim-corner-mocha.png`（Mocha，8×）：侧栏右上圆角的
  顶边与右边是同一条细线，**没有一侧更亮**，也没有断开的半截框。
- 顶边那道 `inset 0 1px 0 rgba(255,255,255,.42)`（暗色 8%）是玻璃的「边缘高光」，只有 1px、
  且在 Latte 上是白压浅底、几乎不可见 —— 属设计件，不是 #22 的那条亮边。

## 结论

`0.7.2` 上 #22 的三条与后续四条**均未回归**，无需改动。本次仍为零代码改动。

## 但扫出一个**新的**同类问题：焦点环画在输入框自己的方框上

`[data-dsh-glass] :focus-visible { outline: 2px solid brand 85%; outline-offset: 1px }` 是全局规则。
宿主的两处搜索框（`input`）**自身没有边框、没有圆角、没有背景**，视觉「框」在祖先的胶囊容器上：

| 位置 | 输入框 | 玻璃关 | 玻璃开 |
|---|---|---|---|
| 模型面板搜索 | `input._input_14sgc_25` 235×16，祖先 `_searchRow` 249×26 | `outline: none` | `outline: 2px solid` Mocha 蓝 85%，offset 0.67px |
| 侧栏会话搜索 | `input.GakraW_searchInput` 151×20，外层是圆角胶囊 | `outline: none` | 同上 |

于是屏幕上出现一个**直角的蓝色小方框，套在圆角胶囊内部、贴着文字**（截图
`focus-ring-input.png` / `focus-ring-search.png`，8× 与 6×）。玻璃关掉即消失 —— 100% 由本皮肤引入。

判性质：按钮 / 会话行上的同一圈环是**唯一**焦点指示（宿主这些元素没有自己的环，实测 `box-shadow: none`、
`border: 0`），属于无障碍必需；问题只在「裸输入框」这一类——环画在了错误的盒子上（文字框而非胶囊）。

可选修法（**未实施，等取向**）：

1. 只给非文本控件留环：`:focus-visible:not(input):not(textarea)`，代价是这两处搜索框没有可见焦点；
2. 把环挪到可视容器：`… :has(> input:focus-visible) { outline: …; border-radius: inherit }`，需要宿主的容器钩子；
3. 折中：输入框上保留环但补 `border-radius` + `outline-offset: 3px`，让它至少是圆的、离开文字一点。

三条都要真机验收（尤其第 2 条要确认容器钩子稳定），且属于观感/无障碍取舍，需维护者定。
